Manual steps — the human checklist. Everything else should be handled by
bootstrap, Brewfile, or project-local tooling.

Interactive installs (App Store, passwords, biometrics, admin):

- xcode clt       Run `xcode-select --install` first — git needs the Command
                  Line Tools before anything else works. Install full Xcode
                  only for native Apple-platform work, and keep it current if
                  it lives in /Applications.
- tailscale       https://tailscale.com/download — ships as a .pkg needing
                  admin install and macOS network-extension approval. The
                  Homebrew cask has the same sudo requirement.
- 1password       https://1password.com/downloads — interactive installer
                  app; keeps biometrics + browser pairing intact. SSH-agent
                  and secrets truth.
- google drive    https://www.google.com/drive/download/ — ships as a .pkg
                  needing an admin install.
- proton auth     Install Proton Authenticator from the App Store. It is an
                  iOS-style wrapped app and has no Homebrew cask.

Post-bootstrap checks:

- orbstack        Open once after bootstrap if it has not completed first-run
                  setup. Docker Desktop should stay absent after migration.
