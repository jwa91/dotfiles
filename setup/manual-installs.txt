Manual installs (intentionally outside Homebrew AND outside setup/apps.sh)

GUI apps with a scriptable official download live in setup/apps.sh.
This file lists the rest: interactive installers, App Store items, and
on-demand toolchains — plus the CLI tools bootstrap installs automatically.

- xcode
  website: Mac App Store
  reason: full Xcode (not just CLI tools) is required; CLI tools are installed via xcode-select --install in bootstrap, but the full IDE must come from the App Store.

- tailscale
  website: https://tailscale.com/download
  reason: macOS network extension approval flow is interactive and more reliable via the official installer/app flow.

- 1password
  website: https://1password.com/downloads
  reason: ships as an interactive installer app rather than a drag-install, and the standalone install keeps biometrics and browser-extension pairing intact. Current primary password manager and SSH agent during the (delayed) Proton Pass migration.

- google drive
  website: https://www.google.com/drive/download/
  reason: ships as a .pkg requiring an admin install; direct installer is more reliable than the chronically lagging brew cask.

- go
  website: https://go.dev/dl/
  reason: official installer is the rule for Go. Since 1.21 the toolchain directive in go.mod pins and auto-downloads per-project toolchain versions, so no extra version manager is needed.

- rust (rustup)
  website: https://rustup.rs
  reason: rustup is the canonical Rust toolchain manager; cargo/rustc stay out of Homebrew.

- codex
  website: https://github.com/openai/codex
  reason: install from official releases; the brew cask lags and a global npm install is against the runtime policy.

- amp (Sourcegraph)
  install: curl -fsSL https://ampcode.com/install.sh | bash
  website: https://ampcode.com
  reason: official install script is the canonical method; bootstrap.sh runs this automatically.

- claude code
  install: curl -fsSL https://claude.ai/install.sh | bash
  reason: native installer self-updates faster than the brew cask; bootstrap.sh runs this automatically. Migrating off the cask: brew uninstall --cask claude-code, then rerun bootstrap.
