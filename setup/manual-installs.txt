Manual installs — the human checklist. Everything else: see Brewfile.

Interactive installs (App Store, passwords, biometrics, admin):

- xcode           Mac App Store. Day-1 note: run `xcode-select --install`
                  first — git needs the CLT before anything else works.
- tailscale       https://tailscale.com/download — interactive
                  network-extension approval.
- 1password       https://1password.com/downloads — interactive installer
                  app; keeps biometrics + browser pairing intact. Current
                  SSH-agent and secrets truth.
- google drive    https://www.google.com/drive/download/ — ships as a .pkg
                  needing an admin install.
- docker desktop  `brew install --cask --adopt docker-desktop` when wanted;
                  kept out of the Brewfile because the cask prompts for an
                  admin password mid-install (CLI symlinks in /usr/local/bin).

On-demand toolchains (install when a project needs them):

- go              https://go.dev/dl/ official installer; go.mod's toolchain
                  directive pins per-project versions natively.
- rust            https://rustup.rs — rustup is the canonical toolchain
                  manager; cargo/rustc stay off Homebrew.
